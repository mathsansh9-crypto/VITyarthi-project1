Carbon Footprint Tracker & Eco-Coach

---

Carbon Footprint Tracker & Eco-Coach is a Python application designed to help individuals calculate, understand, and reduce their daily environmental impact. By inputting routine activities—such as energy usage, transportation modes, diet, and waste generation—the application leverages standard emission factors to compute a precise estimate of the user's daily and annual carbon footprint.

Beyond basic calculation, the system acts as an intelligent "Eco-Coach." It analyzes individual lifestyle patterns to pinpoint primary emission drivers and delivers personalized, actionable recommendations for sustainable living. Users can set custom reduction goals, explore "what-if" scenarios (e.g., switching to public transit or adopting a plant-based diet), and track their progress through visually intuitive data summaries.

Built entirely in Python, the project emphasizes accessible sustainability. It transforms complex environmental metrics into clear, meaningful insights, empowering users to make climate-conscious choices and build long-term eco-friendly habits.
